# AgroMoz Smart Farming Assistance Platform

## Overview

AgroMoz is a smart farming assistance platform developed to support farmers and agricultural stakeholders through digital technology. The platform provides tools for crop management, agricultural monitoring, farmer assistance, and access to modern farming solutions in an interactive and user-friendly environment.

The system aims to improve agricultural productivity, simplify access to farming information, and promote digital transformation within the agricultural sector.

---

## Objectives

The main objectives of the project are:

- Assist farmers with smart agricultural solutions
- Improve access to farming information and resources
- Provide a modern and responsive digital platform
- Enhance user interaction through an intuitive interface
- Support sustainable and efficient farming practices

## Installation Guide

### Clone the Repository

```bash
git clone https://github.com/your-username/Agri-main.git
```

### Navigate Into the Project

```bash
cd Agri-main
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will run locally at:

```bash
http://localhost:3000
```

## Firebase Configuration

The project uses Firebase services for authentication and database management.

Create a `.env` file and configure the following environment variables:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```
